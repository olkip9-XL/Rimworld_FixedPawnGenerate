# Rimworld-FixedPawnGenerate
可以生成固定人物的mod

A mod that can generate fixed characters

## Introduction
这个mod可以生成固定的世界人物，只需要编写xml配置文件

This mod allows the generation of fixed world characters by simply writing an XML configuration file.
